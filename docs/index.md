## О проекте / About
Кодекс не является идеологией или религией. Это рабочий этический стандарт для тех, кто принимает решения и несет ответственность за последствия.

The Code is not an ideology or a religion. It is a working ethical standard for those who make decisions and bear responsibility for the consequences.
