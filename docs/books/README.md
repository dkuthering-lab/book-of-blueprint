# Книги проекта

Ниже собран предварительный скелет книг по диалогу из `source/dialog.md`.

Единое название проекта: **Кодекс Разумного Созидания**.

## Новая логика структуры

Чтобы Кодекс был "рабочим и принятым", материалы разделены на два слоя:

- `ru/KODEKS/PRINYATYY_KODEKS` — действующее ядро (что принимаем как норматив).
- `ru/KODEKS/KONTEKST_EPOKHI` — внешние условия, гипотезы, спорные и аналитические блоки.

`KODEKS` — это один Кодекс. Не отдельные параллельные книги.

## Языковая структура

- `books/ru/` — русские исходники и издания.
- `books/en/` — английские издания и словарь терминов для согласованного перевода.

Русский корпус перенесен в `books/ru/`. Английский слой (`books/en/`) развивается как отдельный локализованный контур.

## Карта текущих папок

- `ru/CODEX_CHELOVEKA` -> технический черновой источник для слоя `PRINYATYY_KODEKS` (не в публичной витрине как самостоятельная книга).
- `ru/OBSHCHEE_BLAGO_I_SPRAVEDLIVAYA_EKONOMIKA` -> часть норматива + часть прикладной этики.
- `ru/SVETSKAYA_RELIGIYA_SMYSLA` и `ru/TEKHNOKOSMOS_I_FRONTIR` -> в первую очередь слой `KONTEKST_EPOKHI`.
- `EDITIONS` -> цельные сборки для просмотра всего корпуса.

Смысл разделения: Кодекс остается стабильным, а контекст эпохи обновляется без риска "ломать" принятые принципы.
