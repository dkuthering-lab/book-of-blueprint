# Политика работы с источниками

Краткие правила для всех материалов "Принятого Кодекса".

## Обязательные правила

1. Любой значимый факт или цифра должен иметь источник.
2. Любой источник должен быть оформлен через `docs/docs/docs/docs/docs/docs/books/ru/KODEKS/PRINYATYY_KODEKS/SOURCE_NOTE.md`.
3. Факт, интерпретация и мнение маркируются отдельно.
4. При появлении новых данных автор обновляет вывод, а не скрывает расхождение.

## Правило обновления

- Если источник устарел, рядом с тезисом ставится пометка "требует ревизии".
- Ревизия фиксируется открыто: "было / стало / почему изменили".

## Запрещенные практики

- "пересказ пересказа" как единственный источник;
- анонимные "эксперты" без проверяемой квалификации;
- выбор данных только под заранее выбранный вывод.
