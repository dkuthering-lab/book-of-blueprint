# Принятый Кодекс: Путеводитель

Краткий путеводитель по основным идеям и инструментам Кодекса.

## Как читать

1. Прочитайте 3 базовых текста (15-20 минут).
2. Выберите 1-2 чеклиста для своей роли (редактор, управленец, преподаватель, участник сообщества).
3. Примените на одном реальном решении.

## Шаг 1. Базовые тексты

1. `books/ru/OBSHCHEE_BLAGO_I_SPRAVEDLIVAYA_EKONOMIKA/01_eticheskiy_kriteriy_horosho_i_ploho.md`  
   Простая рамка оценки: улучшает ли решение жизнь людей и общества.

2. `books/ru/OBSHCHEE_BLAGO_I_SPRAVEDLIVAYA_EKONOMIKA/06_manifest_obshchego_blaga.md`  
   Короткий социальный контракт Кодекса.

3. `books/ru/KODEKS/PRINYATYY_KODEKS/PRAVA_CHELOVEKA_I_SOVMESTIMOST_KODEKSA.md`  
   Правовой минимум: развитие не против прав человека.

## Шаг 2. Прикладные инструменты

- Для медиа: `books/ru/KODEKS/PRINYATYY_KODEKS/MEDIA_EDITORIAL_CHECKLIST.md`
- Для переговоров: `books/ru/KODEKS/PRINYATYY_KODEKS/NEGOTIATION_CHECKLIST.md`
- Для проектов Земля-Космос: `books/ru/KODEKS/PRINYATYY_KODEKS/ZEMLYA_KOSMOS_CHECKLIST.md`
- Для работы с фактами: `books/ru/KODEKS/PRINYATYY_KODEKS/SOURCE_NOTE.md`

## Шаг 3. Мини-практика

Возьмите одну актуальную ситуацию (рабочий проект, публикация, спорное решение) и ответьте:

- где здесь реальная польза для людей;
- где риск вреда;
- какие данные подтверждают решение;
- что нужно изменить до запуска.

Если после проверки вы видите, что решение стало яснее и честнее, Кодекс работает.
