# Контекст эпохи

Здесь размещаются материалы, полезные для понимания среды, но не являющиеся "принятой нормой" Кодекса.

## Что относится к этому слою

- анализ текущего состояния планеты;
- технологические и социальные сценарии;
- гипотезы о будущем и спорные модели;
- материалы для обсуждения, доработки и проверки.

## Основные источники в проекте

- `books/ru/TEKHNOKOSMOS_I_FRONTIR/INDEX.md`
- `books/ru/SVETSKAYA_RELIGIYA_SMYSLA/INDEX.md`
- отдельные аналитические главы из `books/ru/OBSHCHEE_BLAGO_I_SPRAVEDLIVAYA_EKONOMIKA/`

## Правило использования

Контекстные материалы не отменяют принятый Кодекс.  
Они служат как "радар": помогают уточнять решения и вовремя обновлять практики.
